## 3. Single biggest blocker

**EO state coverage in the conformer library.**

obj-025 confirmed that classical SMD with a head-head distance bias
cannot open the αVβ3 headpiece in 3 ns even at force constant
k=1000 kJ/mol/nm² (rate ~0.07 Å/ps; ~320 ns to reach the 60 Å EO
target). The current 615-frame library spans CV0 = [47.3, 85.0] Å
— BC + Intermediate + EC fully covered, but **zero EO frames** (>85
Å). Reviewer A will flag this immediately: "Your CV0 range misses
the truly extended states. What happens at 90 Å — does the head
domain orient correctly?"

Why unresolved: SMD is the cheapest available method. The proven
alternatives are all multi-week:

- αIIbβ3 string method structures (Ferg-Lab) require force-field
  re-parameterization for αVβ3 + membrane embedding rebuild.
- Metadynamics with CV2 needs a well-tempered protocol + Plumed setup.
- Replica exchange needs at least 8 parallel replicas at A100-class.

Each route is gated on one of: (a) RunPod A100 windows, (b) GROMACS
install with Plumed (we run OpenMM), (c) PACE A100 budget. The
project has been able to make progress on tip calibration, library
quality, and sim-real fits without resolving this — but the
publication blocker is that EO is missing.

Method:
