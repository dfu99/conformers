## 3. Single biggest blocker

**EO state coverage in the conformer library.**

obj-025 confirmed that classical SMD with a head-head distance bias
cannot open the αVβ3 headpiece in 3 ns even at force constant
k=1000 kJ/mol/nm² (rate ~0.07 Å/ps; ~320 ns to reach the 60 Å EO
target). The current 615-frame library spans CV0 = [47.3, 85.0] Å
— BC + Intermediate + EC fully covered, but **zero EO frames** (>85
Å). Reviewer A will flag this immediately: "Your CV0 range misses
the truly extended states. What happens at 90 Å — does the head
domain orient correctly?"

Why unresolved: SMD is the cheapest available method. The proven
alternatives are all multi-week:

- αIIbβ3 string method structures (Ferg-Lab) require force-field
  re-parameterization for αVβ3 + membrane embedding rebuild.
- Metadynamics with CV2 needs a well-tempered protocol + Plumed setup.
- Replica exchange needs at least 8 parallel replicas at A100-class.

Each route is gated on one of: (a) RunPod A100 windows, (b) GROMACS
install with Plumed (we run OpenMM), (c) PACE A100 budget. The
project has been able to make progress on tip calibration, library
quality, and sim-real fits without resolving this — but the
publication blocker is that EO is missing.

## 5. Ship list — the ONE thing for the next 24h

**Free-energy profile ΔG(CV0) from V1+V2 fitted trajectories.**

This addresses reviewer D (Elber/Chipot) directly: "Where is the
free-energy profile along your CV distance? 1-3ns of steering doesn't
give you ΔG."

Insight: we have **1645 unbiased frames** of fitted CV0 from V1 (379)
+ V2 (1266) of the AFM-overlay pipeline. These are NOT MD-steered;
they are the populations the real HS-AFM samples. We can compute an
*experimental* ΔG = −kT log P(CV0) at T=300 K straight from those
populations, no extra MD required.

Concrete steps (all CPU, all local):

1. New script `pipelines/afm-overlay/scripts/free_energy_profile.py`.
2. Load `fitted_coords_median_reanchored.npy` from
   `results/afm_pipeline/v7_smoothed_final/video1/` and `video2/`.
3. Compute CV0 per frame using the existing α-head/α-tail centroid
   definition (from `pipelines/conformer-library/scripts/build_library_metadata.py`).
4. Concatenate V1 + V2; histogram with 1 Å bins; smooth with KDE.
5. ΔG(CV0) = −kT log P(CV0), normalized to ΔG=0 at the global minimum.
6. Plot: ΔG curve + state-band overlays (BC=65, EC=78, EO=>85) +
   shaded EO-coverage gap + Chen 2023 / ACS Nano 2024 reference points
   if available in literature notes.
7. Save: `results/afm_pipeline/free_energy_profile/{free_energy.png,
   delta_g.npy}` and `figures/free_energy_profile_v1.png`.
8. Append obj-038 to `tasks/objectives.yaml`; bump
   `tasks/planning.md` Recently Completed.

Time estimate: 60–90 min including figure iteration.

  EO_CV2≥42) appear in `analyze_state_kinetics.py`,
  `render_projection_overlay.py`, and `pipelines.md`. Centralize
  these in a single Python constant module.
- **Memory-only inputs**: `simulate_afm_video.py` requires
  `AFMFOLD_ROOT` env-or-clone. Not validated at startup; failure mode
  is an opaque ImportError.
- **No CI**. SLURM scripts have no `bash -n` syntax check on commit.
